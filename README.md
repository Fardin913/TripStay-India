# TripStay India — MERN travel discovery project

TripStay is a student-friendly MERN application for discovering **hotels, destinations and attractions located in India only**. It includes React + Vite, an Express REST API, MongoDB, JWT authentication, wishlists, booking records, Stripe Checkout test-mode integration, a Google Maps explorer, and a responsive contact/footer experience.

> **Learning/demo project:** Hotel, destination and attraction records are sample data, not live inventory. The booking flow does not check real room availability. Stripe is configured for test mode only; it must not be used to collect real payments. Contact details are placeholders.

## 1. Features

- Home page with search, featured stays and destination highlights.
- Indian hotel directory with search and hotel detail pages.
- 24 sample Indian destinations and 30 attractions/places across India.
- Places directory with text search and city filter.
- Google Maps explorer that appends `India` to map searches. An Embed API key is required for the embedded map; an external Google Maps link is also provided.
- Register/login with hashed passwords and JWT authentication.
- Wishlist and booking history.
- Stripe Checkout test-mode flow with server-side price calculation and payment verification.
- About, Contact, responsive navigation and footer sections.

## 2. Requirements / installations

Install these before running the project:

1. **Node.js LTS (18 or newer)** — https://nodejs.org/en/download/
2. **MongoDB Community Server** — https://www.mongodb.com/try/download/community
3. **MongoDB Compass** (GUI to view your database) — https://www.mongodb.com/products/tools/compass
4. **Visual Studio Code** — https://code.visualstudio.com/Download
5. **Postman** (optional, for API testing) — https://www.postman.com/downloads/

After installing Node.js, restart VS Code and verify in PowerShell:

```powershell
node -v
npm -v
```

On Windows, MongoDB is normally installed as a service. Check it in PowerShell:

```powershell
Get-Service MongoDB
```

If it is stopped, open PowerShell as Administrator and run:

```powershell
Start-Service MongoDB
```

## 3. Extract and open the project

1. Extract the downloaded ZIP file.
2. Open the extracted `tripstay-mern` folder in VS Code. Open the folder containing the root `package.json`, not only `frontend` or `backend`.
3. Open **Terminal → New Terminal** in VS Code.
4. Confirm that the terminal is in the project root:

```powershell
Get-Location
Get-ChildItem
```

You should see `package.json`, `frontend`, `backend`, and `README.md`.

## 4. Install all project dependencies

Run these commands from the project root, in this order:

```powershell
npm install
npm run install:all
```

The first command installs the root development utility. The second installs the backend and frontend dependencies, including the Stripe SDK.

## 5. Create environment files

Still in the project root, run:

```powershell
Copy-Item backend\.env.example backend\.env
Copy-Item frontend\.env.example frontend\.env
```

### Backend environment — `backend/.env`

Open `backend/.env`. Set your local MongoDB connection and a long random JWT secret:

```env
PORT=5000
MONGO_URI=mongodb://127.0.0.1:27017/tripstay
JWT_SECRET=replace_this_with_a_long_random_secret
CLIENT_URL=http://localhost:5173
STRIPE_SECRET_KEY=sk_test_replace_with_your_test_secret_key
STRIPE_CURRENCY=inr
```

Keep the Stripe secret key in the backend `.env` only. Never put it in a React `VITE_` variable, share it publicly, or commit `.env` files to GitHub.

### Frontend environment — `frontend/.env`

```env
VITE_API_URL=http://localhost:5000/api
VITE_GOOGLE_MAPS_API_KEY=replace_with_your_google_maps_embed_api_key
```

The Google Maps key is optional for starting the rest of the website. Without it, the map page displays setup instructions and an external Google Maps search link. Restart Vite after changing a frontend environment variable.

## 6. Set up Google Maps (optional, for the embedded map)

1. Open the official Google Maps Embed API quickstart: https://developers.google.com/maps/documentation/embed/quickstart
2. Create/select a Google Cloud project and enable **Maps Embed API**.
3. Create an API key in Google Maps Platform → Keys & Credentials.
4. Restrict the key to Maps Embed API and to your website/referrer where possible. Do not publish an unrestricted key.
5. Paste the key into `frontend/.env` as `VITE_GOOGLE_MAPS_API_KEY=...`.
6. Stop and restart the frontend development server.

Google documents that Maps Embed API requests are available at no charge, but a valid API key and a billing-enabled Google Cloud project are required. See the official usage page: https://developers.google.com/maps/documentation/embed/usage-and-billing

The app's own places collection contains Indian locations only. Searches generated by the map explorer include `India` in the query. A user can still navigate Google Maps independently after opening the external link.

## 7. Configure Stripe test mode (optional)

The checkout code is intentionally restricted to a Stripe **test secret key** beginning with `sk_test_`. It rejects a live key. The backend calculates the booking amount from the hotel record; the browser does not decide the payment amount.

1. Use a Stripe account that is legitimately available to the account holder and eligible for the intended use. Do not attempt to bypass Stripe's account, age, identity, business or regional requirements. A parent/guardian, teacher or project administrator should handle any account-related setup where required.
2. In the Stripe Dashboard, use **test mode** and copy the test secret key.
3. Paste it into `backend/.env` as `STRIPE_SECRET_KEY=sk_test_...`.
4. Keep `STRIPE_CURRENCY=inr` for the sample hotel prices.
5. Restart the backend after changing `.env`.

**India account note:** Stripe's current India guidance says new Indian Stripe accounts are invite-only. Payment methods and eligibility depend on the account and region; this demo configures card checkout and does not implement UPI. Check the current official guidance before relying on Stripe: https://support.stripe.com/questions/details-needed-to-create-an-account-with-stripe-in-india and https://support.stripe.com/questions/supported-payment-methods-currencies-and-businesses-for-stripe-accounts-in-india

For safe development, keep test mode enabled. No real charges are intended by this project. If you do not have access to an eligible Stripe test account, the website and all non-payment features can still run; the checkout endpoint will show a configuration message.

## 8. Insert sample India data

Make sure MongoDB is running. From the project root run:

```powershell
npm run seed
```

Expected terminal output includes:

```text
Inserted 20 Indian hotels, 24 Indian destinations and 30 Indian attractions.
```

Then open MongoDB Compass and connect to:

```text
mongodb://127.0.0.1:27017
```

Open the `tripstay` database. You should see collections such as `hotels`, `destinations`, and `places`. The `users` and `bookings` collections are created when you register and make bookings.

**Important:** The seed script clears and recreates the `hotels`, `destinations`, and `places` collections each time it runs. Do not run it again if you have manually edited those collections and want to keep your changes. It does not clear user or booking collections.

## 9. Run the full project

From the root `tripstay-mern` folder:

```powershell
npm run dev
```

This starts both servers:

- Frontend: http://localhost:5173
- Backend API: http://localhost:5000/api
- Backend health check: http://localhost:5000/api/health

Keep the terminal running. Press `Ctrl + C` to stop both servers.

If you prefer separate terminals:

**Terminal 1 — backend**

```powershell
npm run dev --prefix backend
```

**Terminal 2 — frontend**

```powershell
npm run dev --prefix frontend
```

2. Browse Hotels, Destinations and Places.
3. Search attractions and filter the Places page by city.
4. Open Map and test an Indian place. Add a Maps API key to show the embedded map.

### Postman checks

- `GET http://localhost:5000/api/health`
- `GET http://localhost:5000/api/hotels`
- `GET http://localhost:5000/api/destinations`
- `GET http://localhost:5000/api/places`
- `POST http://localhost:5000/api/auth/register`

Register body (Body → raw → JSON):

```json
{
  "name": "Test User",
  "email": "test@example.com",
  "password": "test1234"
}
```

Login endpoint: `POST http://localhost:5000/api/auth/login`

```json
{
  "email": "test@example.com",
  "password": "test1234"
}
```

Protected routes require the JWT returned by login in the header:

```text
Authorization: Bearer YOUR_TOKEN
```

## 12. API routes

- Auth: `POST /api/auth/register`, `POST /api/auth/login`, `GET /api/auth/me`
- Hotels: `GET /api/hotels`, `GET /api/hotels/:id`, `POST /api/hotels` (protected)
- Destinations: `GET /api/destinations`, `GET /api/destinations/:id`
- Places: `GET /api/places`, optional `?search=fort`, `?city=Jaipur`, `?category=Beach`
- Wishlist: `GET /api/wishlist`, `POST /api/wishlist/:hotelId`, `DELETE /api/wishlist/:hotelId` (protected)
- Bookings: `GET /api/bookings/my` (protected)
- Payments: `POST /api/payments/checkout-session`, `GET /api/payments/confirm?session_id=...`, `POST /api/payments/cancel` (protected)

## 13. Common problems

**`node` or `npm` is not recognized**

- Reinstall Node.js LTS, make sure the PATH option is enabled, and restart VS Code/PowerShell.

**MongoDB connection refused / `ECONNREFUSED 127.0.0.1:27017`**

- Check the MongoDB service with `Get-Service MongoDB`.
- Start it from an Administrator PowerShell with `Start-Service MongoDB`.
- Confirm `MONGO_URI` in `backend/.env`.

**`Cannot find module`**

- Run `npm install` and `npm run install:all` from the project root.

**Frontend says Network Error**

- Confirm the backend is running on port 5000.
- Confirm `VITE_API_URL=http://localhost:5000/api` in `frontend/.env`.
- Restart Vite after changing frontend `.env`.

**Stripe checkout says not configured**

- Confirm `STRIPE_SECRET_KEY` is a valid test key starting with `sk_test_` in `backend/.env`.
- Restart the backend. Check that the account can use the selected currency and payment method.

**Google map asks for an API key / shows an error**

- Enable Maps Embed API, create a key, restrict it appropriately, and set `VITE_GOOGLE_MAPS_API_KEY` in `frontend/.env`.
- Restart the frontend.

**Port 5000 or 5173 is already in use**

- Stop the other process using that port, or change the port and corresponding frontend API URL.

## 15. Important project limitations

- Sample catalogue data is fictional/demo content; it is not a live hotel inventory or a guarantee of availability.
- Booking dates and totals are validated, but real-time room availability and cancellation/refund workflows are not implemented.
- Stripe is test-mode only. No production payment handling, webhook reconciliation, refunds, tax invoices or UPI integration is included.
- Google Maps embedded view requires your own Maps Embed API key.
- The Contact page uses a `mailto:` link and placeholder contact information; replace it with a real approved contact method if you publish the project.
- Before production, add stronger validation, rate limiting, secure deployment configuration, monitoring, booking inventory logic, payment webhooks and privacy/legal review.
